# Arbitrage design brief

Preserve SignalForge’s warm graphite field, ivory type, Newsreader display, Geist UI and mono data. The hero is an editorial thesis beside a computed economic proof—not a fabricated live ticker. Use hairline rules, open columns and restrained mineral-green/amber/rust decision states. Never rely on color alone.

Scale: display 56–100px, inspector 36–58px, UI 13–16px, metadata 10–12px. Spacing follows 8/16/24/32/64px intervals. Mobile stacks the inspector, keeps payout/decision in the compact Radar, and provides a real navigation disclosure. No cards for generic sections, no logos without a license, no trading-chart theater.

Motion communicates changed routes and decision state. The existing GSAP story remains isolated; Motion owns the new local comparison elements. Reduced motion uses immediate static states. All controls are labeled, keyboard-operable and focus-visible. Live supply, controlled economics, user scenarios and unknowns remain locally identified.
