# Agent Objective Command Surface

The objective is the focus; the observed network is context; compilation is the action.
Preserve the existing Newsreader / Geist / Geist Mono typography and graphite / ivory
palette. Use a split editorial canvas (roughly two-thirds writing, one-third route),
not a container card. Keep generous outer whitespace and narrow internal rules.

- Display: fluid 42–76px; objective: 22–32px; body: 15–17px; data: 10–12px mono.
- Spacing: 8, 16, 24, 40, 64px; mobile collapses the route underneath the objective.
- Color: inherited warm graphite, ivory, mineral gray, restrained indigo for focus.
- Interaction: native labeled dropdowns, visible keyboard focus, Cmd/Ctrl+Enter,
  text-only examples, local heuristic preview with no network calls while typing.
- Motion: scoped GSAP entry rails and preview changes; 250ms local transitions.
  All content exists in the static state. Reduced motion disables transitions.
- Truth: catalog counts come from the API; demo and unavailable states are explicit.
  Observation is not provider testing, authorization, execution, or a price guarantee.
- Accessibility: semantic form, independent labels, focusable controls, readable
  narrow layout, no rotating placeholder while focused or when text is present.

Network becomes an editorial explorer with URL-backed filters. Developer proof calls
the same bounded public REST/MCP interfaces as another agent; it does not simulate a
successful HTTP response. Route contracts remain the central artifact.
