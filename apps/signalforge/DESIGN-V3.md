# SignalForge V3 — instrument, not interface theater

Preserve the V2 composition and all domain behavior. Add detail through three
layers: nearly invisible contour geometry, precise route traces, and archival
evidence marks. No new imagery, dependencies, backend, or telemetry.

- Display: Newsreader; interface: Geist; system truth: Geist Mono. Existing scale.
- Rhythm: 8px baseline, 24/48/96px group spacing; hairlines instead of panels.
- Palette: warm charcoal / ivory; restrained periwinkle paths and mineral green
  corroboration. Paper/ink reserved for reports. No decorative gradients beyond
  a faint, localized background light.
- Motion: 2.15s hero, scrubbed route, one-time evidence arrival, 250–400ms controls
  and page entrances. Ambient points settle once; no perpetual idle loops.
- Content is present before JavaScript. Reduced motion is the final composed
  state. Mobile keeps a vertical static route and no pointer effects or pinning.
- Animated values come from existing fixtures: $0.25 budget, $0.08 modeled route,
  $0 actual spend, two modeled independent source families. Explicit demo labels
  sit beside every explanatory visualization. No live confidence telemetry.
- Keep native links, buttons, keyboard focus, semantic headings and source text.
  Decorative marks are hidden from assistive technology; evidence is not.
